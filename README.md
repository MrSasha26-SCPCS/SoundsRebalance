# SoundsRebalance (v1.0)
SCP: CS plugin

Добавляет возможность менять громкость некоторых звуков в игре, а именно (настройки в конфиге):
- `scp049_volume` - громкость шагов SCP-049 (по умолчанию: `0,8`);
- `scp106_volume` - громкость шагов SCP-106 (по умолчанию: `0,9`);
- `scp173_volume` - громкость SCP-173 (по умолчанию: `0,8`).

**Важное примечание:** если значение находится между 0 и 1, то используйте `,`, а не `.`.
